# Datasets Directory

This directory is reserved for local datasets used in the Machine Learning Mathematics notebooks.

Currently, all examples in the notebooks use synthetically generated arrays (via NumPy) or symbolic matrices (via SymPy) to demonstrate fundamental linear algebra concepts without requiring external file downloads.

If external datasets (such as CSV files or image matrices for SVD compression) are added in the future, place them in this directory. Large binary data files are ignored by git according to the rules in `.gitignore`.
